First time setup (one minute)

Paste your GitHub personal access token below. It is saved only in this browser — it is never sent anywhere except to GitHub. The token needs the repo scope (classic token) or Contents read/write (fine-grained token for this repo).

No token yet? GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → tick repo. Full steps are in README.md.
